## Scientific status

The original frozen v8.6.3 Gate 5 analysis remains methodologically distinct.
The later Design Lab tested a prospective GLMM architecture. Phase 7 completed
4,000 GLMM fits under its locked simulation design; under that phase's
prespecified calibration rule, the correlated M1 architecture was retained as
the candidate for a future prospectively preregistered study.

This is **simulation-based methodological validation**, not live confirmatory
evidence that a self-referential processing effect exists.
